# Security Policy

Thank you for helping keep Spectre Search secure and private.

## Reporting a vulnerability

If you believe you have discovered a security issue in this project, please do not open a public GitHub issue.

Instead, please report it privately through GitHub's private vulnerability reporting for this repository.

When reporting, please include:
- a clear description of the issue
- the affected version or commit
- steps to reproduce the problem
- the potential impact
- any proof-of-concept or sample payload, if safe to share

We ask that you allow a reasonable amount of time for the issue to be reviewed and addressed before disclosing it publicly.

## Security issues considered in scope

Reports related to the following are in scope:
- authentication or authorization bypass
- session or token misuse
- unsafe handling of user input
- injection vulnerabilities
- cross-site scripting (XSS)
- server-side request forgery (SSRF)
- data exposure or privacy regressions
- insecure defaults or unsafe configuration
- issues that could materially affect the privacy, safety, or integrity of users

## Security issues not considered in scope

The following are generally not considered in scope unless they demonstrate a concrete security impact:
- best-practice suggestions without a clear vulnerability
- missing HTTP headers without a demonstrated exploit
- low-impact denial-of-service reports
- issues in third-party services not controlled by this project
- theoretical concerns without a practical exploitation path

## Response expectations

The project maintainer will do their best to:
- acknowledge the report promptly
- assess the risk and impact
- investigate the issue
- coordinate a fix where appropriate
- determine a responsible disclosure timeline

We appreciate responsible disclosure and reports that help keep the project safer for everyone.

## Responsible disclosure

Please avoid sharing details publicly until a fix has been released or a reasonable disclosure plan has been agreed. Thank you for helping protect the project and its users.
